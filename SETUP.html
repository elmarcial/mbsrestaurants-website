Setup Guide

MBS Restaurants — Deployment Checklist

Follow these steps in order to deploy mbsrestaurants.com. Estimated total time: 20–30 minutes.

1

Create GitHub Repository

~3 min
1

Go to github.com → New repository

Name it: mbsrestaurants-website

Set to Public (required for Cloudflare Pages free tier). Click Create repository.

2

Initialize and push from your terminal

cd ~/Sites/mbsrestaurants-website
git init
git add .
git commit -m "Initial build — MBS Restaurants demo site"
git remote add origin https://github.com/YOUR_USERNAME/mbsrestaurants-website.git
git push -u origin main

Replace YOUR_USERNAME with your GitHub username (likely elmarcial based on your other repos).

2

Create Cloudflare Pages Project

~5 min
1

Log in to Cloudflare Dashboard

Go to dash.cloudflare.com → click Workers & Pages in the left sidebar.

2

Create a new Pages project

Click Create application → Pages tab → Connect to Git.

3

Select your repository

Choose mbsrestaurants-website from the list. If it doesn't appear, click Add account and grant Cloudflare access to your GitHub.

4

Configure build settings

Project name: mbsrestaurants-website

Production branch: main

Build command: (leave blank)

Build output directory: (leave blank or /)

Click Save and Deploy. Your site will be live at a .pages.dev URL in about 60 seconds.

5

Add your custom domain

Once deployed, go to your Pages project → Custom domains tab → Set up a custom domain.

Enter mbsrestaurants.com and click Continue.

Since your domain is already on Cloudflare, it will auto-configure the DNS. Click Activate domain.

✅ mbsrestaurants.com will go live within a few minutes after this step.
3

Deploy the Cloudflare Worker (Email API)

~3 min
1

Open your terminal and navigate to the project

cd ~/Sites/mbsrestaurants-website
2

Deploy the Worker

wrangler deploy

This creates a Worker named mbs-restaurants-api. It will be available at:

https://mbs-restaurants-api.jasonmarcial95.workers.dev
⚠️ If wrangler says "Authentication required", run wrangler login first and follow the browser prompt.
4

Set the Resend API Key Secret

~2 min
1

Run the secret command

wrangler secret put RESEND_API_KEY

Wrangler will prompt you: Enter a secret value:

Paste your Resend API key (from the Resend dashboard → API Keys) and press Enter.

⚠️ Never paste your API key directly into the wrangler.toml file. Using wrangler secret put keeps it encrypted and out of Git.
5

Verify mbsrestaurants.com in Resend

~5–10 min
1

Open Resend dashboard

Go to resend.com/domains → click Add Domain.

Enter: mbsrestaurants.com and click Add.

2

Add DNS records in Cloudflare

Resend will show you 3–4 DNS records to add. Go to dash.cloudflare.com → mbsrestaurants.com → DNS → Records.

Add each record exactly as Resend shows. Typically:

  • 1× TXT record (SPF)
  • 1× TXT record (DKIM)
  • 1× CNAME record (DKIM)
3

Verify in Resend

Click Verify Domain in the Resend dashboard. DNS propagation is usually instant on Cloudflare. If it fails, wait 2 minutes and try again.

✅ Once verified, emails will send from orders@mbsrestaurants.com
6

Test the Full Flow

~5 min
1

Open one of the demo pages

Visit mbsrestaurants.com/demo-mexican.html (or the .pages.dev URL before the custom domain is live).

2

Add items and go to checkout

Add a few items to the cart. Click the cart icon → Proceed to Checkout.

3

Fill out the form with your real email

Use your own email (jasonm@mbsandcompany.com) to confirm the email arrives. Use any fake values for the other fields (name, card, address).

4

Click Place Order and check your inbox

You should receive a nicely formatted order confirmation email within 30 seconds. If it ends up in spam, mark it as "Not Spam" — this trains the filters.

✅ If the email arrives, everything is working. The site is live.
7

Future Deploys (Ongoing)

1 min per deploy
1

For HTML/content changes (Pages)

cd ~/Sites/mbsrestaurants-website
git add .
git commit -m "your message"
git push

Cloudflare Pages auto-deploys within 60 seconds of every push.

2

For Worker (API) changes only

cd ~/Sites/mbsrestaurants-website
wrangler deploy
