================================================================
MBS RESTAURANTS — NEXT STEPS TO GO LIVE
================================================================
Everything in ~/Sites/mbsrestaurants-website/ is built and
committed locally. Follow these steps in order.
================================================================

STEP 1 — CREATE GITHUB REPO
----------------------------------------------------------------
1. Go to github.com → New repository
2. Name it: mbsrestaurants-website
3. Set to Public (required for free Cloudflare Pages)
4. Do NOT initialize with README (the repo already has files)
5. Click "Create repository"

Then run these commands in your terminal:

  cd ~/Sites/mbsrestaurants-website
  git remote add origin https://github.com/YOUR_USERNAME/mbsrestaurants-website.git
  git push -u origin main

Replace YOUR_USERNAME with your actual GitHub username.


STEP 2 — CREATE CLOUDFLARE PAGES PROJECT
----------------------------------------------------------------
1. Log into dash.cloudflare.com
2. Go to Workers & Pages → Pages → Create a project
3. Click "Connect to Git" → authorize GitHub → select mbsrestaurants-website
4. Framework preset: None
5. Build command: (leave blank)
6. Build output directory: /  (just a forward slash)
7. Click Save and Deploy
8. Wait ~30 seconds for the first deploy to finish


STEP 3 — ADD CUSTOM DOMAIN TO PAGES
----------------------------------------------------------------
1. In your Pages project → Custom domains → Set up a custom domain
2. Enter: mbsrestaurants.com
3. Cloudflare will auto-configure DNS since the domain is already there
4. Also add: www.mbsrestaurants.com (optional redirect)
5. Wait a few minutes for DNS propagation


STEP 4 — DEPLOY THE CLOUDFLARE WORKER
----------------------------------------------------------------
Run this in your terminal from the project folder:

  cd ~/Sites/mbsrestaurants-website
  wrangler deploy

Expected output:
  Published mbs-restaurants-api
  https://mbs-restaurants-api.jasonmarcial95.workers.dev

If wrangler asks you to log in, run:
  wrangler login


STEP 5 — SET THE RESEND API KEY SECRET
----------------------------------------------------------------
Run this command (it will prompt you to paste the key):

  wrangler secret put RESEND_API_KEY

1. Go to resend.com → API Keys → Create API Key
2. Copy the key (starts with re_)
3. Paste it when prompted in the terminal
4. Press Enter

The key is stored encrypted in Cloudflare — never in any file.


STEP 6 — VERIFY MBSRESTAURANTS.COM IN RESEND
----------------------------------------------------------------
1. Go to resend.com → Domains → Add Domain
2. Enter: mbsrestaurants.com
3. Resend will show you DNS records to add (TXT + MX records)
4. Go to Cloudflare DNS for mbsrestaurants.com
5. Add each DNS record exactly as shown in Resend
6. Click "Verify" in Resend — usually takes under 5 minutes


STEP 7 — TEST THE FULL FLOW
----------------------------------------------------------------
1. Open any demo page:
   https://mbsrestaurants.com/demo-mexican.html
   https://mbsrestaurants.com/demo-italian.html
   https://mbsrestaurants.com/demo-chinese.html

2. Add a few items to the cart
3. Click "My Order" → "Proceed to Checkout"
4. Enter YOUR REAL NAME and YOUR REAL EMAIL
5. Fill in any fake values for CC, phone, address
6. Check the T&C box
7. Click "Place Order"
8. You should receive the confirmation email within ~30 seconds
